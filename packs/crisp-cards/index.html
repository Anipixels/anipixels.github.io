  • Deckbuilder (37) - attack / skill / power / defend plays, energy, relics, potions, a tuned combo ladder, discard reshuffle, run map

  • Status (29) - heal, buff, debuff, poison, energy; burn, bleed, freeze, stun, thorns, cleanse, vulnerable, regen

  • Chips (31) - chip clack, stack, pile push, bet; tosses, slides, the chip riffle, dealer's rake, all-in, payout cascades
  • Dice & Coins (38) - dice shake, roll, land, dice cups and trays, wooden dice; coins flipped, dropped, stacked, spun, poured
  • Roulette & Wins (18) - roulette spin with ball drop, a seamless wheel loop, ball rattle, jackpot, small / medium / big wins, lose
  • Slots (30) - lever pulls, spin buttons, reel-spin loops, tuned reel stops, wins, near miss, coin tray, payout and count-up loops
  • Table (16) - the dealer's jobs: card shoe, dealer button, knock and tap, discard tray, cash drop box, counting banknotes

  • UI (39) - buttons, hovers, confirm, cancel, not enough energy, rewards, gold, shop buy, map select; tabs, page turns, toggles, deck editor
  • Ambience (2) - two seamless stereo table loops (no voices): card room, roulette table

Details

  • 419 sounds in 15 folders (226 named sounds; 149 of them come in 2-5 takes), so a dealt hand does not sound robotic.
  • 9 seamless loops, including 2 stereo table ambiences of 16 s.
  • Loudness-matched, peaks at or below -1 dBFS; WAV 44.1 kHz / 16-bit and OGG Vorbis.
  • Tuned: stingers in C major / C minor; combo steps and reel stops climb the C major pentatonic scale.
  • Godot 4 sound bank included (one line to play any sound, takes picked for you); Unity notes included.
  • Every v1.0 file is unchanged in v2.0: same names, same folders, same audio.

Formats and engines

  • WAV: 44.1 kHz, 16-bit, stereo (for editing and highest quality).
  • OGG Vorbis: small files, ready for Godot, Unity, GameMaker and web.
