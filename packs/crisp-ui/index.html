Crisp UI: 583 UI sound effects for games + 4 style sets

Every sound comes as WAV and OGG. Version 2.0 (12 Nov 2026) grew it from 242 sounds, free for everyone who already owns it.

Details

  • 583 sounds in 16 folders (263 named sounds; 102 of them come in 3 or more takes), so repeated clicks and pickups do not sound robotic.
  • 4 style sets x 36 files with identical names (click, hover, select, confirm, cancel, error, open, close, toggles, slider tick, notify, text blip, unlock): point your code at another folder and the whole UI changes style.
  • 3 tuned ladders: slider_step (8 steps), combo_up (4 steps), star (3 steps); 3 seamless stereo loops: charge, loading, scroll.
  • Loudness-matched (quiet hovers, louder confirms), peaks at or below -1 dBFS; WAV 44.1 kHz / 16-bit and OGG Vorbis, plus a 48 kHz / 24-bit master of the 341 new sounds.
  • Godot 4 sound bank included (tested headless in Godot 4.7.2); a Unity package and notes (not tested inside Unity); sounds.csv data sheet.
  • Every 1.x file is unchanged in v2.0: same names, same folders, same audio.

Formats and engines

  • WAV: 44.1 kHz, 16-bit, stereo (for editing and highest quality).
  • OGG Vorbis: small files, ready for Godot, Unity, GameMaker and web.
  • Every sound is loudness-matched, starts on its first sample (no dead air) and peaks at or below -1 dBFS.

How is Crisp Cozy different from Crisp UI?

Crisp UI is clean and neutral: clicks, glass, bright chimes. Crisp Cozy is warm and rounded: wood, kalimba, bubbles, paper, and it covers whole cozy games, not only menus. Measured across both packs, the average spectral centre of Crisp Cozy is about 1090 Hz against 1910 Hz for Crisp UI. The interface folder names match, so you can mix them.
